Side project · 2026 · React, Node.js, PostgreSQL

Dexiosi Flow

Wedding venues in Greece still run guest lists on an Excel file that goes back and forth with the family, sometimes in more than a dozen versions. With Dexiosi the family fills in the list from a link, and the venue sees every change as it happens.

My part

All of it: the idea, the design and the code. The front end is React. You arrange the floor plan by dragging tables around, each event gets its own copy of the layout, and once the list is locked the venue sees exactly what changed after that. The back end is Node.js with PostgreSQL, and changes reach the venue live over Server-Sent Events. There are 21 automated tests.

Choices I made

The family doesn't need an account. They get one link and one page that works on a phone. On the venue's side, events that need attention come first, so nothing urgent gets buried.

Side project · 2026 · React, Tailwind, Node.js, SQLite, Stripe

In-Site QR Ordering

Customers at a café scan the QR code on their table, order and pay by card. The order shows up straight away on the staff screen, split between bar and kitchen.

My part

I designed and built all three parts: the menu customers see on their phone, the board the staff work from, and an admin area for the platform. Behind them is an Express API with separate roles for owners, cashiers, waiters, kitchen, bar and runners. Payments go through Stripe. The server works out the price from the menu, so nobody can change it in the browser, and an order only counts once Stripe confirms the payment.

Choices I made

Each item is tracked per station. If the salad is ready but the coffee isn't, the waiter can see that and take the salad now. The QR stickers point to a short code rather than a table, so moving a table doesn't mean printing new stickers.

From Figma design to MJML email, with AI

What it does
You upload an image of the email design from Figma, plus a JSON file with the fonts and spacing. The tool sends both to an AI model and gets back the email in MJML. From there you keep working in an editor that shows errors on every change, with desktop and mobile previews side by side.
Also
Each client has its own account, where you upload their images and reusable components. Before sending, the tool runs its QA checks, and an AI model looks at screenshots of the email from Mailgun to catch visual mistakes.
Built with
React, TypeScript, Node.js and PostgreSQL. I built it on my own in 2026.

Push notification packages for Adobe Campaign Classic

The problem
A client ran our scripts for push notifications in Adobe Campaign Classic, and every delivery had to be packaged in a very specific way: four JavaScript files with fixed names and content, some variables added or changed, then minified, encoded, renamed and zipped under a fixed name. Checking it meant undoing all of that by hand to confirm each variable and its content. One package took three to four hours.
What it does
It pulls the content from the company portal through its API, writes the four files, minifies and encodes them, names them and zips them. Then it unzips and decodes its own output and checks every variable, and shows an alert or an error if anything is off.
Result
A few seconds instead of up to four hours for each package.
Built with
Plain browser JavaScript and the portal's API. I built it on my own in 2023.

Email builder for a banking client

The problem
The client gave us one master HTML email that had to go out under about 50 different brands. Each brand needed its own copy, links, logo and setup. Preparing the HTML, the setup files and the QA for one version took about three days.
What it does
You enter each brand's details and the tool builds every version from the master template, ready to hand over to the client. It also runs the checks we used to do by hand, on the content and on every link.
Result
The tool produced the files and ran the checks in seconds, so all 50 versions were delivered in about three days, where before each one took that long.
Built with
Node.js, HTML, plain browser JavaScript and Bootstrap. I built it on my own in 2022.
